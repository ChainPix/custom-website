# XML Formatter & Validator — Manual Test Checklist

- **Valid XML**: Paste sample and format → output prettified, status success.
- **Indent options**: Switch between 2 and 4 spaces; output updates accordingly.
- **Invalid XML**: Break a tag; format shows clear parse error.
- **Large input guard**: Input >200KB shows size warning and prevents formatting.
- **Copy/download**: Copy places formatted XML on clipboard; download saves `formatted.xml` with matching content.
- **Reset**: Reset restores sample and clears output/error.
- **Accessibility**: `aria-live` status updates; output region labeled; controls focusable with visible outlines.
